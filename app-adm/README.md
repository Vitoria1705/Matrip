# Matrip Admin

Painel administrativo da plataforma Matrip. Permite gerenciar usuários (alterar tipo de acesso) e guias cadastrados.

## Como rodar

```bash
npm install
npm run dev
```

O app espera que o backend (`backend-java`) esteja rodando em `http://localhost:3000`.

## Tecnologias

- React + TypeScript
- Vite
- React Router
- Tailwind CSS
